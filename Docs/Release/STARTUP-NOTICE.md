# 시작 화면 광과민성 안내

게임 실행마다 Unity 기본 스플래시 다음, 첫 로비 조작 전에 정적인 안내 화면을 표시한다.
불투명 배경으로 로비를 덮고 배경 소리와 로비의 포인터·키보드·설정 단축키 입력을 막는다.
안내 문구를 표시한 뒤 최소 2초가 지나면 계속하기, 효과 줄이고 계속하기, 종료를 선택할 수 있다.
자동으로 화면을 넘기거나 점멸·카운트다운 애니메이션을 사용하지 않는다.

게임의 기존 언어 선택기를 함께 사용한다. 일반 실행은 저장한 게임 언어, 운영체제 언어,
영어 대체 순서다. 지원 언어는 한국어·영어·일본어다. 개발용 `-language=` 실행 인자가
있으면 기존 언어 선택기 규칙에 따라 우선한다. IP나 국가 정보를 수집하지 않는다.

문구는 기존 `UITable`과 `ui.csv`에 있으며 `Startup_` 키 6개를 사용한다. 기존 Galmuri
폰트와 해당 폴백을 프리팹에서 참조하고 사용자 폰트 에셋을 수정하지 않는다.

‘계속하기’는 효과 설정을 보존한다. ‘효과 줄이고 계속하기’는 기존 설정 API를 통해
카메라 흔들림·입자·잔상·점멸·화면 효과·후처리 6개를 끄고 저장한 뒤 로비를 보여 준다.
효과 설정은 이후 설정 메뉴에서 다시 변경할 수 있다. 로비로 돌아올 때 안내가 반복되지는 않는다.

안내는 광과민성 안전성 평가나 법적 보증을 대신하지 않는다. 효과 감소가 모든 위험을
제거하지 않는다는 문구를 포함한다. 증상 시 중단·의료진 상담과 병력 관련 안내는
[Microsoft XAG 118](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/118)과
[Capcom 건강 안내](https://captown.capcom.com/en/health_warning)를 참고해 짧게 작성했다.

검증: `BallARetroSceneProbe.cs`에서 초기 선택·지연 중 Submit 차단·3개 언어의 텍스트 넘침,
포인터 전달, 오디오 복구, 두 계속하기 동작, 로비 복귀 시 반복 방지를 검사한다.
`Run-PlayerSmoke.ps1`은 실제 Windows 실행 파일에서 현지화된 안내의 준비 로그까지 확인한다.
엔진 스크린샷은 UI 검증 자료이며 STOVE 클라이언트 촬영 영상이 아니다.
