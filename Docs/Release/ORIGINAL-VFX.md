# BALL-A-RETRO 자체 제작 포털·로딩 효과

2026-11-08 출시 수정 작업에서 작성했다. 외부 효과의 텍스처, 셰이더, VFX Graph 또는
메시를 복제하지 않고 Unity 입자와 UI 사각형의 위치·색·시간 변화를 코드로 구성했다.

- `BallARetroPortalVfx.cs`: 색상 포털은 타원형 빛 번짐·연무·긴 흰 불티, 별도 불꽃 포털은
  금색 불티가 접선 방향으로 퍼지는 소용돌이로 구분한다. 색상 포털 384개, 불꽃 포털 2,048개
  한도 내에서 버퍼를 재사용하며 일시정지를 따른다.
- `BallARetroPixelParticle.shader`: 기존 이름을 유지하되, 텍스처 없는 노이즈와 부드러운
  감쇠를 계산하는 URP 셰이더다. 동일 간격의 픽셀 점 원형을 제거했다.
- `OriginalVfx/RetroPortal.prefab`, `PixelParticle.mat`: 아홉 포털이 공유하는 프리팹·머테리얼.
  위치·회전을 유지하며 색상 포털의 반지름 .7, 세로 비율 1.3과 불꽃 포털의 시작 반지름 2를 반영한다.
  부모 스케일을 따르는 `Hierarchy` 설정과 기존 연무의 보라·빨강·노랑 계열을 복구했다.
  빨강·파랑 포털은 원래 `2F` 레이어(6)를 복구하여 기본 보드에서 숨고 2층 진입 때 보인다.
  기존 레일 진입·퇴장 및 카메라 전환을 따르며, 임의의 2초 파티클 종료를 추가하지 않는다.
- `BallARetroLoadingVfx.cs`: 로비의 시작/튜토리얼 버튼 행 아래에 작은 효과를 표시한다.
  로비는 그대로 보이며 투명 패널이 중복 입력을 차단한다. 실제 버튼 위치와 화면 크기를 기준으로
  정렬하고 다음 씬 활성화 시 숨긴다. 시간 정지와 무관하게 움직이며 파티클 설정을 끄면
  정지된 상태 표시를 유지한다.

기존 Hovl 포털, Cool Visual Effects의 Portal2, VisualX 로딩 효과를 출시 씬에서 교체했다.
이전 에셋은 개발 저장소에서 삭제하지 않는다. `Verify-PackedAssets.ps1`는 실제 빌드 보고서에
교체된 업체의 이미지·머테리얼·VFX Graph가 남으면 실패하고 자체 제작 머테리얼·셰이더도 확인한다.
기존 폭죽 프리팹과 그 리소스는 이번 교체 대상이 아니다.

첫 빌드의 실제 포함 목록에서 추가 참조 4개를 발견해 정리했다. 팩맨 공의 잔상은
텍스처를 사용하지 않는 `BallARetroPixelTrail.shader`로 교체하고, 구형 랭킹의 Refresh
버튼은 자체 단색 배경으로 바꿨다. 보드 velvet 머테리얼에 연결된 외부 콘크리트 이미지는
제거하고 기존 기본색·조명 설정을 유지했다. 사용자 볼 머테리얼은 수정하지 않았다.

검증은 격리한 Unity 프로젝트에서 수행한다. 포털 수·두 스타일·입자 움직임·효과 설정,
레일 진입/종료 콜백에 따른 표시·숨김 반복, Rigidbody의 포털 진입·사출·재활성화를 확인한다.
로딩은 버튼 아래 정렬·로비 노출·투명 입력 차단·중복 요청 방지·씬 활성화 후 숨김을 검사한다.
콜백 검사는 실제 공의 충돌부터 레일 이동 완료까지의 수동 플레이 검사를 대체하지 않는다.
프리뷰 카메라로 만든 포털 이미지는 효과 확인용이며 STOVE 클라이언트 플레이 영상이 아니다.
